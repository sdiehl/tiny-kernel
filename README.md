# tiny-kernel

my hacky attempt at a pedagogical dependent type theory kernel in Rust modeled on Lean. About 1800 lines. Don't use this for anything, it's just for fun.

```bash
cargo build
cargo test
```

```bash
cargo run --example demo
cargo run --example tactic
```
